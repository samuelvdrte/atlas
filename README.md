# 🌎 Atlas — Explorando o Mundo

O Atlas é uma plataforma web interativa desenvolvida com React, que permite explorar países do mundo e conhecer informações geográficas, demográficas e climáticas de forma dinâmica e intuitiva.

## 🚀 Funcionalidades

- 🌍 Exploração de países do mundo.
- 🏳️ Visualização de bandeiras nacionais.
- 📊 Informações sobre população, capital, idiomas e moedas.
- 🗺️ Mapa-múndi interativo com localização dos países.
- 🌤️ Consulta de informações climáticas.
- 🧠 Quizzes de conhecimentos geográficos.
- 🔎 Pesquisa e navegação entre países.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3
- APIs REST
- Leaflet
- Open-Meteo

## ⚙️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/samuelvdrte/atlas.git
```

2. Entre na pasta:

```bash
cd atlas
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o projeto:

```bash
npm run dev
```

5. Acesse o endereço disponibilizado pelo Vite no terminal.

## 🎯 Objetivo

O objetivo do Atlas é unir tecnologia, geografia e educação em uma única plataforma, proporcionando uma experiência interativa e acessível para quem deseja conhecer melhor os países e suas características.
